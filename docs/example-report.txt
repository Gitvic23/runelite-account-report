DATA COVERAGE AND LIMITATIONS
All values are last observed, not live knowledge. Cached observations may be stale.
Snapshots from different times can disagree; location quantities are NEVER added together.
This plugin cannot observe changes on mobile or another client. Reopen RuneLite, log in,
and open your bank to refresh it. Login alone does not refresh the bank.
Bank uses the full server item container, independent of searches, filters and tabs.
Placeholders and nonpositive quantities are excluded. Original IDs and variants are retained.
Noted items show their unnoted reference ID; neither IDs nor charges are silently merged.
Excluded: POH, STASH, seed vault, death/group storage, potion storage and other containers.
Container ownership does not reveal contents, charges, stored supplies or account unlocks.
Useful-item matching covers only the bundled catalog; absence does not prove non-ownership.
Quest API entries include miniquests/subquests; this API exposes no reliable type flag.
Quest counts are API-entry counts, not a count of full quests or quest points.
Deferred: diaries, Slayer task/points/rewards, minigame currencies, unlock flags, Word export.
Private identifiers and credentials are never included. No account data is sent anywhere.
Disabled sections also exclude their containers from the useful-items summary.
