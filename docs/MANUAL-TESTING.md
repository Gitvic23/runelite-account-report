# In-game checklist — not yet executed

Run these checks yourself in the development client. No automated game input is provided. To test first observation, preserve existing plugin reports/caches elsewhere before using a fresh plugin data folder. Never share credentials or private caches.

1. **Login before opening the bank.** Enable the plugin, log in and wait a few seconds. Verify name/type/levels and skills. With no previous bank observation, export should say "Bank not yet observed", not empty. With a cache, expect its old timestamp labeled cached. Verify inventory/equipment have separate times, and a genuinely empty inventory/equipment container says observed empty.
2. **Open bank and export.** Close/reopen if the plugin was just enabled. Compare random bank items and large stacks, not just useful items. Verify original IDs/variants, alphabetical order and no placeholders/fillers. If possible test a genuinely empty bank. Compare all skills, XP/next-level XP, maximum levels, quest groups and quest points with the client. Miniquests/subquests remain API entries.
3. **Searches, filters and tabs.** Export the full bank view, a search hiding most items, individual tabs and filters. Owned item lists must remain identical unless items actually move. Test bank tag tabs if installed.
4. **Move items.** Withdraw a tracked pouch, equip/unequip items, close the bank and move an inventory item. Check occupied equipment slots and independent times. Old bank data can disagree with inventory, but no combined quantity should appear. Test charged jewelry, degraded pouches, imbued helmets and notes: raw IDs stay separate. No claims about stored contents or charges.
5. **XP and quest updates.** Gain XP naturally, wait up to 15 seconds or export, and compare actual level/XP. Progress a quest through normal play, wait up to 60 seconds or export, and verify its group/count changes. Unavailable states should be Unknown.
6. **Hop/reconnect.** Export with bank closed, hop, and export again. Bank items/time survive as cached. Other sections refresh after valid login. Open bank to refresh its time. A separate world mode should have its own cache/report.
7. **Logout/restart.** Save a bank snapshot and log out: export/copy should be disabled. Restart normally, log into the same character and export before opening the bank. Expect its old bank/time, then a new time after opening the bank. Toggle the plugin off/on and verify exactly one sidebar icon and working exports. Forced process termination can lose in-flight writes.
8. **Switch characters/rename.** Observe A's bank, then log into B. B must never show A's cached name/items/times. Switch back and try quick switches while loading/exporting. A renamed character should retain its cache and random latest filename, with its fresh name in the report. Missing internal identity must keep export disabled.
9. **Buttons/settings.** Copy and paste into Notepad; compare with TXT. Open folder in Explorer and check non-ASCII text. Export twice with history off: one latest file updates. Turn history on: expect an extra timestamped file. Disable sections and check their rows are also omitted from useful-items results; coverage/times remain visible. Confirm no credentials/private account identifiers in TXT.
10. **Automatic exports.** Default off: no reports until manual export. Turn it on, wait at least a minute, and check one latest-file update. Frequent XP/item changes must not write a report every event/tick. Confirm another update after another minute, manual exports still work, and turning auto off stops periodic report writes (snapshot caching continues). Double-click Export: no overlapping/partial writes. Disk/clipboard failures should produce clear feedback.

Record RuneLite/plugin/Windows/Java versions, which checks passed/failed and exact mismatches. Review logs/screenshots before sharing. Plugin Hub review, if requested in the future, would not replace functional testing.

Version 1.1 also requires the [unlock/boss-counter checks](PROGRESSION.md#storage-settings-and-accuracy-checks): Knight Waves, prayer unlock flags, explicit zero versus unobserved counts, normal/harder modes, personal system updates, cache upgrade/restart and character isolation. The original user-confirmed export does not validate these new fields until they are checked in-game.
